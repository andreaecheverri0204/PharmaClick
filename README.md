PharmaClick

Proyecto de sistema de gestión de ventas farmacéuticas desarrollado como parte de mi formación en la Técnica Profesional en Programación de Sistemas de Información en el Politécnico Colombiano Jaime Isaza Cadavid
PharmaClick es una aplicación web orientada al control de inventarios y gestión de ventas de productos farmacéuticos. El sistema permite realizar el seguimiento completo de las transacciones, desde la selección de artículos hasta el historial de ventas detallado, garantizando una administración eficiente de los procesos de venta.

El proyecto fue desarrollado integrando Desarrollo Web y herramientas de Bases de Datos

HTML, CSS y JavaScript
PHP.
MySQL ( a través de phpMyAdmin).
Visual Studio Code
Ejecutada en entorno local (XAMPP/Apache).
